## 🔍 How to use the application

Once you open the software, you will see a list of categories on the left side of the screen. Click on any category to expand the list of available providers. Each entry shows a link to the provider and a short summary of the data they offer.

If you need a specific type of information, use the search bar at the top of the interface. Type a keyword like "weather" or "currency" to filter the results.

The application refreshes the index automatically. You always have access to the current list of 1613 sources without needing to update manually. 

## 💡 Common Questions

**Does the software cost money?**
The application is free to use. All providers listed within the application offer a free plan for developers.

**How do I report a broken link?**
If a source link does not work, open the settings menu and click "Report Issue." Describe the problem and hit send.

**Can I use this for business projects?**
You can use the indexed APIs for many types of work. Check the specific terms of use provided by each API owner before you launch a public product.

**Do I need a special account?**
The application does not require you to create an account. You can search and browse the full list immediately. Some individual API providers require a unique key to access their data, but the application displays instructions on how to get those if they are needed.
